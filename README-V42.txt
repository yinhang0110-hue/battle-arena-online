BATTLE ARENA V42 — ILLUSTRATED RPG EDITION

This version ships with actual illustrated PNG character/monster/boss art and JPEG battle backgrounds. Files reside in public/assets/ and must be kept when uploading to GitHub. No gameplay or save keys were intentionally changed. It uses original generated artwork rather than assets from Xenoblade.

Deploy: upload all files and public/assets/ into your existing GitHub repository. Render will redeploy. Open https://battle-arena-online.onrender.com/menu.html after deploying.

Testing: run npm test and manually inspect gameplay for sprite alignment.
